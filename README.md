🎯 Sobre o Projeto

O objetivo desta aplicação é consumir a API pública do universo Demon Slayer (Demon Slayer API) utilizando uma aplicação moderna em Blazor WebAssembly (.NET 10+). O sistema permite listar, buscar personagens em tempo real e exibir suas informações detalhadas.

📌 Requisitos Atendidos

[x] Desenvolvido em Blazor WebAssembly (.NET).

[x] Consumo do endpoint paginado da API de Demon Slayer.

[x] Funcionalidade de listagem e busca por nome de personagens.

[x] Exibição de dados completos por personagem:

name (Nome)

age (Idade)

race (Raça)

quote (Citação / Frase marcante)

img (Imagem do personagem)

[x] Código devidamente indentado e organizado.

🚀 Como Executar o Projeto

Certifique-se de ter o .NET SDK instalado em sua máquina.

Clone o repositório:

git clone https://github.com/ryanvictor432/SearchDemonSlayerAPI.git


Navegue até a pasta do projeto:

cd SearchDemonSlayerAPI


Execute a aplicação:

dotnet watch run
